## Concepts Learned

### Two Pointers

Two pointers process an array or string using two positions that move according to the problem conditions.

### Sliding Window

Sliding Window maintains a continuous range of elements and expands or contracts the range efficiently.

### Monotonic Deque

A monotonic deque maintains elements in increasing or decreasing order and is useful for finding minimum or maximum values inside a moving window.

## Complexity

* Squares of Sorted Array: O(n)
* Backspace String Compare: O(n + m)
* 3Sum Closest: O(n²)
* 4Sum: O(n³)
* Subarray Product Less Than K: O(n)
* Subarrays with K Different Integers: O(n) average
* Longest Continuous Subarray: O(n)
